# DecodeLabs Project 2 — Data Classification Using AI

This project was completed as **Project 2 during my Artificial Intelligence Internship at DecodeLabs**.

## Project Overview

A simple supervised machine learning classification project using the **Iris Dataset** and **K-Nearest Neighbors (KNN)** algorithm.

### Workflow

Iris Dataset → Feature Scaling → Train/Test Split → KNN (K=5) → Prediction → Evaluation

## Technologies

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Joblib

## Dataset

- 150 samples
- 4 features
- 3 classes: Setosa, Versicolor, Virginica

## Model

**Algorithm:** K-Nearest Neighbors (KNN)

**K:** 5

## Result

**Accuracy: 93.33%**

## Key Learning

- Supervised Machine Learning
- Classification
- Feature Scaling
- Train-Test Split
- KNN Algorithm
- Model Training & Prediction
- Confusion Matrix
- Precision, Recall & F1 Score
- Model Saving
- Testing with New Data
